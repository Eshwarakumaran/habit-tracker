# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-15

### Added
- Initial release of Spirit of Vengeance
- Dashboard with real-time soul energy tracking
- Habit management (create, edit, delete, complete)
- Gamification system with XP and levels
- Achievement unlocking system
- Calendar view with flame indicators
- Statistics page with interactive charts
- Settings with export/import functionality
- Offline-first architecture with localStorage
- Responsive design for mobile and desktop
- Dark theme with hellfire aesthetic

### Features
- 6 default habits across multiple categories
- Streak tracking and motivation system
- Real-time progress animations
- Achievement system with 8+ achievements
- Weekly and monthly statistics
- Category-based habit organization
- Fully offline - no backend required

### Security
- All data stored locally in browser
- No external API calls
- No tracking or analytics
- Export/import for data portability
